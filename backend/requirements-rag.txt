# Optional RAG dependencies — baked into the Docker image at build
# time so the embedding model is always available when FEATURE_RAG
# is on, with no runtime install race condition (round-3 audit
# follow-up: switched from torch + sentence-transformers to fastembed
# on 2026-05-03 to fit Render Free tier's 512 MB RAM ceiling).
#
# Memory profile per gunicorn worker:
#   - onnxruntime: ~50 MB
#   - paraphrase-multilingual-MiniLM-L12-v2 (int8 quantized): ~120 MB
#   - python + fastapi + sqlalchemy + diğer deps: ~150 MB
#   ─────────────────────────────────────────────────
#   Total: ~320 MB per worker
#
# WEB_CONCURRENCY=1 is required (set in render.yaml). With the
# default 4 workers we'd be at ~1.3 GB and overflow the Free tier.
# A single uvicorn worker is fine for the current 4 K parts + 8
# deals scale; revisit when traffic warrants more concurrency.
#
# Vector dimensions stay at 384 (same as the prior
# sentence-transformers install) so existing Qdrant collections do
# not need to be re-indexed.

# Pinned to 0.5.1 because 0.6.0+ changed the default pooling from
# CLS-token to mean for paraphrase-multilingual-MiniLM-L12-v2,
# which would put new embeddings in a different semantic space
# from anything embedded with the prior sentence-transformers
# library. Collections are empty today so it's not breaking, but
# pinning lets us pre-embed against either library interchangeably
# without surprises.
fastembed==0.5.1
